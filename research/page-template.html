Jev in Claude Code

Which community integrations of TypeSafe's Jev decision model are worth using for daily coding in Claude Code with OpenRouter as the provider, and how to make Claude use Jev without being asked.

Verdict

worth it

When Claude writes app code

Jev launched after Claude's training data. The official typesafe-ai skill, pinned and loaded by description, makes Claude reach for Jev on its own whenever a feature needs a fast typed decision (routing, triage, moderation, gating), with a pinned model, a none option, a short timeout and a fallback.

mostly not

For Claude Code's own decisions

In bypass-permission sessions there are no prompts to auto-approve. Jev scores below Opus on code judgment (about 72% on vulnerable-code checks, overconfident, moved by injected text) and every call sends commands or code to a third party. The protection that matters is deterministic and needs no Jev.

none from the community

MCP servers, one or several

MCP tools run at the model's discretion (one published bench: 0 of 150 unprompted calls), so they are not automatic. Several servers add overlapping verbs, key-handling risk and silent egress, not use. At most one small self-hosted server with a single triage tool, as a three-week trial.

Recommended rollout

A
Knowledge and hardeningnow · no key · no egress

Vendor the official typesafe-ai skill at a pinned commit, add a two-line pointer to CLAUDE.md, protect OPENROUTER_API_KEY in the secret-leak hook, add deny rules for the key directory and hook files.

B
Deterministic Bash brakedays 0–4 · no key · no Jev

A deny-only PreToolUse hook for irreversible commands (force pushes, history rewrites, repo deletion), shadow mode first, enforced per rule and for unattended subagents first. Try plain permission deny rules before code.

C
Prompt-injection tripwiredays 1–7 · needs key · personal repos only

An async PostToolUse check of fetched web text with two Noul questions, warn-only, local pre-filter first, ZDR routing forced, $5 capped key.

D
Only if the logs show a needday 14+ · shadow first

A Jev veto for the ~2% gray-zone Bash commands, and one self-hosted jev_triage MCP tool for bulk relevance triage. Delete either if it does not earn its place by day 30.
